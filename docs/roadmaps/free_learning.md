# Free Learning Roadmaps

## Overview
The Free Learning category focuses purely on foundational programming languages and concepts. These roadmaps are designed to give absolute beginners their first taste of coding without overwhelming them with frameworks or complex architectures.

---

## 1. C Programming Basics
**Duration:** 2-3 Weeks  
**Difficulty:** Beginner  

### Learning Modules
- **Module 1: Introduction to C**
  - History of C and why it matters
  - Setting up the IDE/Compiler (GCC, VS Code)
  - Writing your first "Hello World"
  - Understanding compilation and execution
- **Module 2: Variables & Data Types**
  - Integers, Floats, Chars
  - Variable declaration and initialization
  - Constants and `#define`
- **Module 3: Operators & Expressions**
  - Arithmetic operators
  - Relational and logical operators
  - Assignment and bitwise operators
- **Module 4: Control Flow**
  - If, else if, else statements
  - Switch cases
  - For, while, and do-while loops
- **Module 5: Functions & Scope**
  - Function declaration vs definition
  - Return types and arguments
  - Local vs global scope
- **Module 6: Arrays & Strings**
  - 1D and 2D arrays
  - String manipulation functions (`string.h`)
- **Module 7: Pointers (Basics)**
  - Understanding memory addresses
  - Dereferencing pointers
  - Pointers and arrays

### Mini Projects
- Simple Calculator
- Number Guessing Game
- Temperature Converter

### Skills Gained
- Low-level memory understanding
- Strong algorithmic foundations

## 2. C++ Basics

**Difficulty:** Beginner  

### Learning Modules
- **Module 1: C++ Foundations**
  - Differences between C and C++
  - I/O streams (`cin`, `cout`)

- **Module 2: Data Types & Operators**
  - Primitive types and `auto`
  - Type casting
- **Module 3: Control Structures**
  - Conditional statements
  - Loops and range-based for loops
- **Module 4: Functions**
  - Default arguments
  - Function overloading
  - Inline functions
- **Module 5: Arrays, Strings, and Vectors**
  - C-style strings vs `std::string`
  - Introduction to `std::vector`
- **Module 6: Object-Oriented Programming (OOP) Basics**
  - Classes and Objects
  - Constructors and Destructors
  - Access Modifiers (public, private, protected)

### Mini Projects

  - Setting up IntelliJ IDEA / Eclipse
  - Basic syntax and main method
- **Module 2: Variables & Types**
  - Primitives vs Reference types
  - Type casting and promotion
- **Module 3: Operators & Control Flow**

  - Encapsulation
  - Inheritance

  - Abstraction (Interfaces & Abstract Classes)
- **Module 6: Exception Handling**
  - Try, catch, finally blocks
  - Checked vs Unchecked exceptions

### Mini Projects

## 5. SQL Basics
**Duration:** 2 Weeks  
**Difficulty:** Beginner  

### Learning Modules
- **Module 1: Relational Databases Overview**
  - What is a database? Tables, rows, columns.
  - Setting up SQLite or MySQL locally.
- **Module 2: Data Querying (DQL)**
  - `SELECT` statements
  - Filtering with `WHERE`
  - Sorting with `ORDER BY`
- **Module 3: Data Manipulation (DML)**
  - `INSERT INTO`
  - `UPDATE`
  - `DELETE`
- **Module 4: Functions & Grouping**
  - Aggregate functions (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`)
  - `GROUP BY` and `HAVING` clauses
- **Module 5: Joins**
  - Inner Join
  - Left/Right Join
  - Full Outer Join

### Mini Projects
- Employee Database Creation
- E-commerce Sales Querying
- Student Grades Analyzer

### Skills Gained
- Database querying
- Data extraction and filtering
