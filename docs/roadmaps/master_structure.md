# Master Curriculum Structure (Skill-Based Roadmaps)

Based on your feedback, we are restructuring the hierarchy so that each major **Category (Course)** contains multiple **Skill Roadmaps** (like HTML, CSS, JavaScript), and each of those roadmaps is broken down into Modules and Topics.

---

## 🎨 Course Category: Frontend Development

### 🗺️ Roadmap 1: HTML Mastery
**Overview:** Learn the standard markup language for documents designed to be displayed in a web browser.
**Duration:** 1-2 Weeks | **Difficulty:** Beginner

- **Module 1: HTML Fundamentals**
  - Topic 1: What is HTML and the DOM?
  - Topic 2: Document Structure (`<html>`, `<head>`, `<body>`)
  - Topic 3: Elements, Tags, and Attributes
- **Module 2: Text & Content**
  - Topic 1: Headings, Paragraphs, and Formatting
  - Topic 2: Lists (Ordered, Unordered, Definition)
  - Topic 3: Links and Anchors (`<a>`)
- **Module 3: Media & Embeds**
  - Topic 1: Images and Alt Text
  - Topic 2: Audio and Video tags
  - Topic 3: Iframes
- **Module 4: Forms & Input**
  - Topic 1: The `<form>` element
  - Topic 2: Input types and validation
  - Topic 3: Select, Textarea, and Buttons
- **Module 5: Semantic HTML & Accessibility**
  - Topic 1: Semantic tags (`<header>`, `<footer>`, `<main>`, `<article>`)
  - Topic 2: Introduction to ARIA roles
  - Topic 3: Best practices for screen readers

---

### 🗺️ Roadmap 2: CSS Mastery
**Overview:** Master the language we use to style an HTML document.
**Duration:** 3-4 Weeks | **Difficulty:** Beginner to Intermediate

- **Module 1: CSS Basics**
  - Topic 1: Inline, Internal, and External CSS
  - Topic 2: Selectors, Specificity, and the Cascade
  - Topic 3: Colors, Backgrounds, and Typography
- **Module 2: The Box Model**
  - Topic 1: Margin, Padding, and Borders
  - Topic 2: Width, Height, and Box-Sizing
- **Module 3: Layouts**
  - Topic 1: Normal Flow and Display properties
  - Topic 2: Flexbox Fundamentals
  - Topic 3: CSS Grid Fundamentals
  - Topic 4: Positioning (Static, Relative, Absolute, Fixed, Sticky)
- **Module 4: Responsive Design**
  - Topic 1: Media Queries
  - Topic 2: Fluid typography and Relative Units (rem, em, vh, vw)
- **Module 5: Advanced CSS**
  - Topic 1: Transitions and Transforms
  - Topic 2: Keyframe Animations
  - Topic 3: CSS Variables (Custom Properties)

---

### 🗺️ Roadmap 3: JavaScript Mastery
**Overview:** Learn the programming language that makes web pages interactive.
**Duration:** 6-8 Weeks | **Difficulty:** Intermediate

- **Module 1: JavaScript Basics**
  - Topic 1: Variables (`let`, `const`, `var`)
  - Topic 2: Data Types (Primitives vs Objects)
  - Topic 3: Operators and Math
- **Module 2: Control Flow**
  - Topic 1: If/Else and Switch Statements
  - Topic 2: For, While, and Do-While Loops
- **Module 3: Functions & Scope**
  - Topic 1: Function Declarations vs Expressions
  - Topic 2: Arrow Functions
  - Topic 3: Lexical Scope and Closures
- **Module 4: Data Structures**
  - Topic 1: Arrays and Array Methods (`map`, `filter`, `reduce`)
  - Topic 2: Objects and Destructuring
  - Topic 3: JSON parsing
- **Module 5: The DOM & Events**
  - Topic 1: Selecting and Modifying DOM Elements
  - Topic 2: Event Listeners and Event Bubbling
- **Module 6: Asynchronous JavaScript**
  - Topic 1: Callbacks and Promises
  - Topic 2: Async / Await
  - Topic 3: The Fetch API

---

### 🗺️ Roadmap 4: React.js
**Overview:** A JavaScript library for building user interfaces based on components.
**Duration:** 4-6 Weeks | **Difficulty:** Advanced

- **Module 1: React Fundamentals**
  - Topic 1: JSX and Babel
  - Topic 2: Components (Functional vs Class)
  - Topic 3: Props and Data Flow
- **Module 2: State & Lifecycle**
  - Topic 1: The `useState` Hook
  - Topic 2: The `useEffect` Hook (Component Lifecycle)
- **Module 3: Advanced Hooks**
  - Topic 1: `useRef` and DOM access
  - Topic 2: `useMemo` and `useCallback` (Performance)
  - Topic 3: Custom Hooks
- **Module 4: Routing & Global State**
  - Topic 1: React Router Setup
  - Topic 2: The Context API (`useContext`)
  - Topic 3: Introduction to Redux / Zustand

---

## ⚙️ Course Category: Backend Development

### 🗺️ Roadmap 1: Node.js & Express
**Overview:** Build scalable network applications using JavaScript on the server.
**Duration:** 4-6 Weeks | **Difficulty:** Intermediate

- **Module 1: Node.js Basics**
  - Topic 1: The V8 Engine and Event Loop
  - Topic 2: CommonJS vs ES Modules
  - Topic 3: File System (`fs`) and Path modules
- **Module 2: Express.js Fundamentals**
  - Topic 1: Setting up an Express Server
  - Topic 2: Routing (GET, POST, PUT, DELETE)
  - Topic 3: Request and Response objects
- **Module 3: Middleware & Security**
  - Topic 1: Creating custom middleware
  - Topic 2: Error handling middleware
  - Topic 3: CORS and Helmet

---

### 🗺️ Roadmap 2: SQL & Relational Databases (PostgreSQL)
**Overview:** Master data storage, querying, and relational design.
**Duration:** 3-4 Weeks | **Difficulty:** Intermediate

- **Module 1: SQL Basics**
  - Topic 1: Database schemas and Tables
  - Topic 2: CRUD Operations (INSERT, SELECT, UPDATE, DELETE)
- **Module 2: Advanced Querying**
  - Topic 1: Filtering, Sorting, and Grouping
  - Topic 2: INNER, LEFT, RIGHT, and FULL JOINs
  - Topic 3: Subqueries and CTEs
- **Module 3: Database Design**
  - Topic 1: Primary Keys and Foreign Keys
  - Topic 2: Normalization (1NF, 2NF, 3NF)
  - Topic 3: Indexing for Performance

---

### 🗺️ Roadmap 3: Authentication & Security
**Overview:** Learn how to secure your backend and manage users.
**Duration:** 2-3 Weeks | **Difficulty:** Advanced

- **Module 1: User Authentication**
  - Topic 1: Password Hashing (Bcrypt, Argon2)
  - Topic 2: Session-based Auth vs Token-based Auth
- **Module 2: JSON Web Tokens (JWT)**
  - Topic 1: Generating and signing JWTs
  - Topic 2: Verifying JWTs in middleware
  - Topic 3: Refresh tokens and access tokens
- **Module 3: OAuth 2.0**
  - Topic 1: How OAuth works
  - Topic 2: Implementing Google/GitHub Login

---

## 📊 Course Category: Data

### 🗺️ Roadmap 1: Python for Data
**Duration:** 4 Weeks | **Difficulty:** Beginner

- **Module 1: Python Basics** (Variables, Loops, Functions)
- **Module 2: Pandas Mastery** (DataFrames, Cleaning Data)
- **Module 3: NumPy Fundamentals** (Arrays, Matrices)

### 🗺️ Roadmap 2: Machine Learning Fundamentals
**Duration:** 8 Weeks | **Difficulty:** Advanced

- **Module 1: Data Preprocessing** (Feature scaling, imputation)
- **Module 2: Supervised Learning** (Regression, Classification, SVM)
- **Module 3: Unsupervised Learning** (K-Means Clustering, PCA)
- **Module 4: Model Evaluation** (Cross-validation, ROC/AUC)

---

*Note: This skill-based hierarchy (Course -> Skill Roadmap -> Module -> Topic) completely aligns with your vision where "Frontend" is the overarching category, and the actual "Roadmaps" are HTML, CSS, JavaScript, React, etc.*
